## 2. 전체 정보구조

토스증권의 하단 탭은 콘텐츠 종류보다 사용자의 의도를 기준으로 나뉜다.

```text
토스증권
├─ 증권: 보유·거래
│  ├─ 계좌와 주문
│  ├─ 수익·배당
│  └─ 최근 행동과 맞춤 서비스
├─ 관심: 관찰
│  ├─ 관심 그룹과 종목 목록
│  ├─ AI 시그널 요약
│  └─ 관련 종목과 뉴스
├─ 발견: 탐색
│  ├─ 자산군 바로가기
│  ├─ 이벤트·지수·실시간 이슈
│  └─ 기준별 시장 순위
├─ 피드: 이해·대화
│  ├─ 추천과 팔로잉
│  ├─ 뉴스
│  └─ 분석·교육 콘텐츠
└─ 공통 상세 경로
   ├─ 검색과 AI 시그널 허브
   └─ 종목상세
      ├─ 차트
      ├─ 호가
      ├─ 내 주식
      ├─ 종목정보
      └─ 커뮤니티
```

- 증권 — 이미 가진 계좌와 거래를 확인하고 행동한다.
  - 계좌 잔액과 통화
  - 주문내역, 판매수익, 배당금, 수익분석
  - 최근 본 종목
  - 개인화된 금융 서비스
  - 실시간 차트와 순위
- 관심 — 이미 알고 있는 종목의 변화를 지속해서 관찰한다.
  - 상단 AI 시그널 요약
  - 최근 본, 옵션, 기본, 배당주/ETF 등 사용자 그룹
  - 그룹 추가, 정렬, 편집, 시간외 상태
  - 관심종목과 유사 종목
  - 관심종목 관련 뉴스
- 발견 — 아직 모르는 자산과 시장 기회를 탐색한다.
  - 해외주식, 국내주식, 연금, 옵션, 채권, ETF 바로가기
  - 오늘의 이벤트와 주요 지수
  - 실시간 이슈 티커
  - 거래대금, 거래량, 급상승, 급하락, 인기 순위
- 피드 — 시장을 이해하고 다른 투자자의 관점을 소비한다.
  - 추천: 개인화된 커뮤니티 글과 콘텐츠
  - 팔로잉: 팔로우한 채널과 사람 중심
  - 뉴스: 편집된 실시간 주요 뉴스
  - 콘텐츠: 교육·분석형 카드 콘텐츠
- 공통 깊은 경로
  - 검색
  - AI 핵심 시그널 목록
  - 종목상세
  - 알림과 메뉴

이 구조의 핵심은 **보유·거래 → 관찰 → 탐색 → 이해·대화**의 네 가지 반복 행동을 서로 섞지 않는 것이다. 어느 탭에서든 종목을 누르면 같은 종목상세로 수렴하므로, 탭 간 이동 뒤에도 사용자가 종목 맥락을 잃지 않는다.

## 3. 공통 화면 골격

### 글로벌 헤더

- 화면 제목 옆에 현재 시장 지수와 등락률을 짧게 붙인다.
- 우측에는 AI 진입, 검색, 전체 메뉴를 고정한다.
- 새 항목이 있으면 메뉴나 탭에 작은 점을 붙여 상태를 알린다.
- 헤더가 정보를 설명하기보다 현재 시장 맥락과 전역 행동을 유지하는 역할을 한다.

### 하단 내비게이션

- 증권, 관심, 발견, 피드 네 항목을 큰 아이콘과 짧은 라벨로 고정한다.
- 활성 항목은 아이콘을 채우고 라벨을 밝게 표시한다.
- 영상에서는 뒤로가기 버튼이 하단 내비게이션 왼쪽에 별도 원형 컨트롤로 붙는다.
- 화면 내용과 충분히 분리된 떠 있는 짙은 표면을 사용해 스크롤 중에도 위치가 안정적이다.

### 섹션 구성

- 긴 화면을 여러 카드로 모두 감싸지 않는다.
- 제목, 본문, 얇은 구분선, 넓은 여백과 진한 섹션 밴드로 관계를 만든다.
- 카드는 바로가기, 요약 지표, AI 시그널처럼 독립된 선택 단위에만 사용한다.
- 각 섹션 끝에는 자세히 보기, 비교하기, 재무제표 보기처럼 다음 깊이로 가는 한 줄 행동을 둔다.

## 4. 탭별 설계 패턴

### 증권

첫 스캔 순서는 **계좌 상태 → 거래 결과 → 최근 행동 → 개인화 서비스 → 시장 순위**다. 계좌와 주문이 주인공이고, 콘텐츠나 뉴스는 보조다. 실제 거래 기능이 없는 제품에서 이 구조를 차용할 때는 계좌 카드나 구매 CTA를 흉내 내지 말고, 오늘의 시장 상태와 내 종목 상태 같은 실제 핵심 업무로 바꿔야 한다.

### 관심

- 제목 바로 아래에 관심종목 전체에 영향을 주는 AI 시그널 한 줄을 둔다.
- 사용자 그룹은 가로 탭으로 전환하며 활성 그룹만 채운 표면으로 표시한다.
- 행은 로고와 종목명, 가격과 등락률, 관심 상태의 세 열로 빠르게 읽힌다.
- 목록이 끝난 뒤 유사 종목과 관련 뉴스를 연결해 관찰에서 탐색으로 자연스럽게 확장한다.
- 관심목록 자체와 관련 콘텐츠를 같은 화면에 두되, 목록을 먼저 끝낸 다음 콘텐츠를 보여줘 우선순위를 지킨다.

### 발견

- 검색만 제공하는 화면이 아니라 시장 탐색의 허브다.
- 상단에는 자산군 바로가기를 큰 터치 영역으로 제공한다.
- 이벤트, 지수, 실시간 이슈를 한 줄 시장 맥락으로 묶는다.
- 순위는 거래대금, 거래량, 급상승, 급하락, 인기처럼 사용자가 이해하기 쉬운 기준으로 나눈다.
- 순위 행은 번호, 로고, 종목명, 가격, 등락률, 관심 버튼의 안정된 열을 유지한다.

### 피드

- 추천, 팔로잉, 뉴스, 콘텐츠가 동일한 데이터의 필터가 아니라 서로 다른 소비 방식으로 동작한다.
- 추천과 팔로잉은 작성자, 소속 주제, 팔로우, 반응, 댓글을 포함한다.
- 뉴스는 큰 대표 기사 뒤에 작은 기사 목록을 이어 정보 밀도를 높인다.
- 콘텐츠는 설명형 카드와 이미지로 학습 목적을 강조한다.
- 각 모드에서도 상단 시장 지수를 유지해 콘텐츠를 시장 맥락에서 읽게 한다.

## 5. 종목상세 정보 계층

### 고정 컨텍스트

- 뒤로가기, 종목명, 현재가와 등락률, 관심, 알림을 상단에 고정한다.
- 스크롤이 길어져도 현재 보고 있는 종목과 가격 상태가 사라지지 않는다.
- 차트, 호가, 내 주식, 종목정보, 커뮤니티의 5개 탭을 가격 헤더 바로 아래에 둔다.
- 실제 거래 화면에서는 구매하기 버튼을 하단에 고정해 모든 정보에서 주문으로 바로 전환할 수 있게 한다.

### 차트

- 현재가를 가장 크게 보여준 뒤, 전일 대비 변화와 차트를 배치한다.
- 1일, 1주, 3달, 1년, 5년, 전체 기간을 한 줄로 둔다.
- 최고와 최저만 직접 표기하고 나머지 보조선을 약하게 처리한다.
- 일별·실시간 시세와 상세 차트는 별도의 더 깊은 경로로 둔다.

### 호가

- 가격 사다리, 매수·매도 잔량, 체결강도, 당일 범위, 거래량을 한 화면에 조밀하게 배치한다.
- 매도는 파랑, 매수와 상승은 빨강 계열로 분리한다.
- 주문창과 애프터마켓 상태를 같은 화면 안에 유지한다.

### 내 주식

- 보유와 주문내역을 종목 맥락에서 확인한다.
- 영상의 빈 상태는 주문내역이 없다는 사실을 삽화와 한 문장으로 직접 알린다.

### 종목정보

정보가 아래 순서로 점진 공개된다.

1. 시세와 투자자 동향
2. 뉴스와 공시
3. 투자 지표 요약
4. PER·PBR·PSR 가치평가와 산업 평균 비교
5. 비교 종목 차트
6. 재무 요약 차트와 원문 재무제표
7. 매출·영업이익 실적과 추정치
8. 부채비율·유동비율 안정성과 동종업계 비교
9. 배당 소식과 배당 내역
10. 애널리스트 투자의견과 예상 목표주가
11. 리서치센터의 종목 이슈
12. 회사 정보, 사업 분류와 매출구성

요약 타일에서 비교, 차트, 원문 표로 깊어지는 흐름이 반복된다. 복잡한 수치를 처음부터 표로 보여주지 않고, 사용자가 의미를 이해한 뒤 원자료를 열 수 있게 한다.

### 커뮤니티

- 인기순과 내 프로필을 상단에 두고, 종목에 관한 게시물만 보여준다.
- 작성자 신뢰 단서, 팔로우, 원문 일부, 이미지, 반응 수를 함께 노출한다.
- 화면 하단의 작성 입력창으로 읽기에서 참여로 전환한다.

## 6. AI 시그널의 역할과 화면 문법

### 영상에서의 의미

영상의 토스증권 AI 시그널은 매수·매도 추천보다 **가격이 왜 움직였는지 설명하는 이벤트 신호**에 가깝다. 예를 들어 엔비디아의 양산 개시, 자사주 매입, 목표주가 상향 같은 이유와 해당 자산의 직후 변화를 짧게 묶는다.

비밀노트의 AI 시그널은 관망, 예비 포착, 매수 대기, 보유, 수익확정, 전량 매도라는 전략 상태를 다룬다. 두 용어를 같은 의미로 섞지 않는다. 토스증권에서 참고할 것은 진입 위치, 카드 계층, 필터, 빈 상태와 알림 흐름이며, 판단 의미와 근거 계약은 비밀노트의 기존 전략을 유지한다.

### AI 진입의 네 단계

1. 관심 화면의 한 줄 시그널 — 지금 확인할 이유를 짧게 제시한다.
2. 핵심 시그널 허브 — 전체 뉴스 분석 건수와 함께 내 투자·관심, 국내, 해외를 필터링한다.
3. 종목상세의 문맥형 시그널 — 현재 종목의 가격 변화 이유를 차트와 호가 사이에서 설명한다.
4. 알림 — 중요한 이유가 새로 생겼을 때 사용자가 선택적으로 받는다.

### 시그널 카드 해부

- 대상: 로고, 종목명 또는 시장 자산
- 원인: 한 문장으로 압축한 사건이나 데이터 변화
- 결과: 상승·하락 방향과 변동률
- 시점: 몇 분 전, 몇 시간 전처럼 최신성 표시
- 깊이: 누르면 원인과 영향을 더 자세히 확인

카드가 “사라” 또는 “팔라”를 먼저 말하지 않고, 원인과 결과를 연결한다. 이 구조는 신뢰를 높이고 사용자가 판단을 이어갈 여지를 남긴다.

### 소개와 알림 신청

- “투자의 주도권”을 반복해 AI를 자동 의사결정자가 아니라 이해를 돕는 도구로 소개한다.
- 기능 카드는 변동 이유, 어닝콜, 실시간 이슈, 증시 캘린더처럼 사용자 문제를 중심으로 이름 붙인다.
- 서비스 소개 뒤 투자 위험과 수수료 안내를 길게 제공한다.
- 알림 신청 화면에는 다음에 하기와 알림 받기를 함께 두어 강제하지 않는다.

### 반드시 갖출 상태

- 신호 있음: 이유, 방향, 시점, 근거로 이동
- 신호 없음: “지금은 요약된 시그널이 없어요”처럼 정상 상태로 설명
- 분석 중: 분석 범위와 진행 상태 표시
- 데이터 지연: 마지막 기준 시점과 누락 원인 표시
- 오류: 다시 시도와 대체 확인 경로 제공
- 알림 꺼짐: 알림을 켜면 얻는 이점과 선택권을 함께 제공

## 7. 시각 시스템 관찰

아래 색상은 영상에서 육안으로 추정한 역할값이며 구현용 원본 토큰이 아니다.

| 역할 | 관찰값 | 사용 방식 |
| --- | --- | --- |
| 기본 배경 | 거의 검정에 가까운 남보라·회색 | 긴 화면의 바탕 |
| 상승·주요 거래 행동 | 선명한 핑크 레드 | 상승률, 구매 CTA, 활성 데이터 |
| 하락·매도 측 | 밝은 블루 | 하락률, 호가 반대편, 비교 데이터 |
| AI | 보라에서 하늘색으로 가는 그라디언트 | AI 라벨, 소개 헤드라인, 강조선 |
| 1차 텍스트 | 따뜻한 흰색 | 화면 제목, 현재가, 핵심 문장 |
| 2차 텍스트 | 중간 회색 | 기준일, 설명, 출처, 비활성 탭 |
| 표면 | 배경보다 한 단계 밝은 짙은 회색 | 선택 탭, 시그널 카드, 요약 지표 |
| 구분 | 얇은 회색 선과 더 어두운 밴드 | 긴 페이지의 섹션 경계 |

타이포그래피는 큰 화면 제목, 압도적인 현재가, 중간 섹션 제목, 일반 본문, 작은 메타데이터의 다섯 단계가 명확하다. 숫자는 단위와 부호를 함께 유지하며, 색상만으로 상승·하락을 전달하지 않는다.

## 8. 인터랙션과 모션

- 하단 탭 전환은 좌우 이동과 짧은 페이드를 사용해 같은 깊이의 화면임을 보여준다.
- 긴 종목상세에서는 헤더와 탭이 고정되고 본문만 스크롤된다.
- 가로 스크롤은 자산군 바로가기, 사용자 그룹, 기능 카드처럼 비교적 독립적인 항목에 사용한다.
- 활성 탭은 상위 화면에서 채운 알약 모양, 종목상세에서 밑줄을 사용해 깊이를 구분한다.
- 추정값은 점선과 흐린 막대처럼 실제값과 시각적으로 분리한다.
- 구매, 알림 받기처럼 중요한 행동만 화면 폭 전체 버튼으로 강조한다.

## 9. 비밀노트 현재 구조와의 매핑

| 비밀노트 현재 영역 | 토스증권 참조 영역 | 적용 시 판단 |
| --- | --- | --- |
| 홈 | 증권 + 발견 + 피드 일부 | 현재 한 화면에 시장, AI, 순위, 캘린더, 뉴스를 많이 담고 있어 첫 스캔 우선순위를 더 엄격히 관리한다. |
| 검색 | 발견 | 단순 검색을 넘어 추천, 순위, 이벤트를 묶는 탐색 허브 패턴을 참고할 수 있다. |
| 내 종목 | 관심 | 그룹, 상태 필터, AI 한 줄 요약, 관련 뉴스의 순서를 참고한다. |
| 종목홈 | 차트 + 종목정보의 상단 요약 | 현재가와 오늘의 핵심을 먼저 보여주고 깊은 자료는 아래나 별도 탭으로 보낸다. |
| 기업분석 | 종목정보 | 요약 → 비교 → 차트 → 원문 표의 반복 계층을 적용한다. |
| AI 시그널 | 핵심 시그널 허브 + 종목 문맥형 시그널 | 카드 문법과 알림 진입을 참고하되, 비밀노트의 전략 상태와 근거 정의는 유지한다. |
| 시장 뉴스·브리핑·커뮤니티 | 피드 | 추천, 뉴스, 분석 콘텐츠의 소비 목적을 구분한다. |

토스증권은 주문을 실행하는 증권사 앱이고 비밀노트는 분석 중심의 읽기 전용 제품이다. 따라서 구매하기, 주문창, 계좌 잔액 같은 거래 기능은 복제 대상이 아니다. 비밀노트의 강한 CTA는 AI 시그널 보기, 근거 확인, 다음 조건 보기처럼 실제 제공 기능에 맞춰야 한다.

## 10. 이후 UI 작업의 적용 원칙

1. 화면 하나에 한 가지 사용자 목적을 먼저 세운다.
2. 첫 화면에는 시장 상태, 내 상태, 다음 행동 중 가장 중요한 하나만 강하게 둔다.
3. 관심, 발견, 피드의 역할을 섞어 한 탭이 모든 기능을 떠안지 않게 한다.
4. 종목상세는 현재가 컨텍스트를 고정하고 요약에서 원자료로 점진 공개한다.
5. AI는 결과만 말하지 않고 이유, 기준시점, 근거, 다음 조건을 함께 보여준다.
6. 신호 없음, 데이터 지연, 분석 중, 오류를 정상적인 제품 상태로 설계한다.
7. 카드보다 안정된 행과 섹션 여백을 우선한다.
8. 상승·하락은 색상뿐 아니라 부호, 방향, 문구로 함께 구분한다.
9. 가로 탭과 고정 헤더는 작은 화면, 확대, 키보드, 안전영역에서도 내용 접근을 막지 않게 검증한다.
10. 토스증권의 시각 언어를 그대로 베끼지 않고 비밀노트의 데이터 신뢰와 읽기 전용 역할에 맞게 번역한다.

## 11. 구현 전 확인 질문

- 이 화면의 목적은 보유 확인, 관찰, 탐색, 이해 중 무엇인가?
- 첫 3초 안에 사용자가 봐야 하는 숫자나 문장은 무엇인가?
- AI가 판단을 대신하는가, 이유를 설명하는가, 다음 조건을 안내하는가?
- 요약 뒤에 비교, 근거, 원문으로 내려가는 경로가 있는가?
- 현재가와 기준시점이 긴 스크롤에서도 유지되는가?
- 신호가 없거나 데이터가 늦을 때도 화면이 정직하게 동작하는가?
- 거래 기능처럼 보이는 표현이 실제 제품 권한과 책임을 넘어가지 않는가?
- 모바일 하단 내비게이션과 고정 CTA가 본문을 가리지 않는가?
