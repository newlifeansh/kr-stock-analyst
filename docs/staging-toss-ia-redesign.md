# 스테이징 토스증권 화면 구조 재구현

이 문서는 사용자가 제공한 토스증권 화면 녹화의 실제 시각 구조를 비밀노트의 기존 정보에 대응한 스테이징 설계 기준이다. 거래 기능을 흉내 내거나 토스의 계좌·주문 데이터를 만들지 않고, 기존 공개 데이터·AI 분석·관심종목·뉴스만 같은 화면 문법으로 재배치한다.

- 참조 기준: [토스증권 UI 영상 참조 기준](toss-securities-ui-reference.md)
- 적용 범위: `app.staging_app:app`으로 실행하는 스테이징 화면
- 비적용 범위: `app.main:app`의 프로덕션 HTML·CSS·JavaScript
- 데이터 계약: 기존 API와 렌더링 로직을 그대로 사용하며 스테이징에서 별도 데이터를 만들지 않는다.

## 1. 목표 서비스 구조

```text
비밀노트
├─ 증권 · 시장 상태와 중요한 변화 확인
│  ├─ 오늘의 시장 지수
│  ├─ AI 전략 변화
│  ├─ 관심종목 대응
│  ├─ TOP 50 미리보기
│  └─ 증시 캘린더와 시장 뉴스 미리보기
├─ 관심 · 이미 고른 종목을 지속 관찰
│  ├─ 관심종목 AI 시그널 진입
│  ├─ 관심종목 / 핀 종목
│  ├─ AI 전략 / 종목 뉴스
│  └─ 전체 / 확인 필요 / 흐름 양호
├─ 발견 · 새로운 관찰 대상 탐색
│  ├─ 종목 검색
│  ├─ TOP 50
│  ├─ AI 시그널
│  ├─ 차트 분석과 머니 브리핑
│  └─ AI 탐색 후보
├─ 피드 · 시장을 이해하는 콘텐츠 소비
│  ├─ 시장 뉴스
│  ├─ 머니 브리핑
│  └─ 증시 캘린더
└─ 종목상세 · 모든 진입 경로가 수렴
   ├─ 차트
   ├─ AI 시그널
   ├─ 소식
   ├─ 종목정보
   └─ 커뮤니티
```

하단 내비게이션은 별도 뒤로가기 없이 `증권 → 관심 → 발견 → 피드` 4탭 순서를 고정한다. 이는 `현재 상태 확인 → 지속 관찰 → 새로운 대상 탐색 → 시장 이해`라는 반복 행동 순서다.

## 2. 기존 기능 매핑

| 기존 화면 또는 기능 | 새 위치 | 배치 판단 |
| --- | --- | --- |
| 홈 시장지수 | 증권 상단 | 사용자가 처음 확인할 시장 상태다. |
| 홈 AI 시그널과 관심종목 대응 | 증권 핵심 섹션 | 시장 변화와 내 종목의 연결을 바로 보여준다. |
| TOP 50 | 증권 미리보기 + 발견 바로가기 | 시장 상태 확인과 새로운 종목 탐색 양쪽에 필요하다. |
| 증시 캘린더 | 증권 미리보기 + 피드 모드 | 일정은 시장 맥락이자 해설 콘텐츠다. |
| 시장 뉴스 | 증권 미리보기 + 피드 본문 | 홈에서는 최신 맥락만, 피드에서는 전체 목록을 제공한다. |
| 관심종목과 핀 종목 | 관심 | 저장한 대상의 반복 관찰이라는 한 목적에 묶는다. |
| 종목 추천 | 발견 | 추천 점수는 매수 신호가 아니라 탐색 후보임을 명시한다. |
| 차트 분석 | 발견 및 전체 메뉴 | 특정 종목을 알고 있을 때 사용하는 분석 도구다. |
| 머니 브리핑 | 피드 및 전체 메뉴 | 해설형 콘텐츠 소비 흐름으로 분리한다. |
| 알림 설정 | 전체 메뉴 | 전역 헤더를 토스 화면처럼 세 개의 핵심 동작으로 제한한다. |

## 3. 종목상세 재배치

### 차트

- 미스크롤 헤더에는 종목 시세를 표시하지 않고, 본문 시세 영역이 헤더 아래로 사라진 뒤에만 상단 중앙 종목명·가격·등락을 노출
- 종목 헤더는 좌측 뒤로가기·중앙 종목명/가격/등락률·우측 관심종목의 대칭 3열로 구성하며, 알림과 더보기는 두지 않음
- 현재가, 등락, 기준시점
- 실시간 가격·거래량 차트와 기간 선택
- 거래량, 거래대금, 시가총액, 전일 종가
- 오늘의 요약과 차트분석
- 최근 수급, 핵심 키워드, 투자자별 매매동향

### 종목정보

- 기업 체력 한눈에 보기
- 실적과 수익구조
- 동종업계 수익성
- 판관비와 현금 흐름
- 재무 안정성, 밸류에이션, 투자 체크포인트
- 회사 기본정보는 상세 흐름의 마지막에 둔다.

정보 순서는 `요약 → 비교 → 차트 → 세부 근거 → 회사 원정보`로 깊어진다. 지표 요약은 `라벨·상태 → 핵심값 → 근거`의 같은 위치를 반복한다.

### AI 시그널

- 현재 전략 단계와 핵심 판단
- 보유 비중과 다음 확인 조건
- 최근 1년 신호 시점
- 같은 규칙을 적용한 모의 결과
- 전체 매매내역과 투자 유의 문구

토스의 설명형 시그널 화면 문법을 참고하지만 비밀노트의 전략 단계 의미를 유지한다. 결과만 강조하지 않고 근거, 기준시점, 다음 조건, 표본 한계를 함께 표시한다.

### 소식

- 종목 소식 요약
- DART 공시
- 반복 이슈
- 증권사 리포트와 목표가
- 종목 뉴스와 뉴스 온도

### 커뮤니티

- 종목 관련 공개 커뮤니티 반응
- 출처와 수집 상태

## 4. 크기와 간격 계약

| 역할 | 기준 |
| --- | --- |
| 기본 터치 영역 | 44px 이상 |
| 하단 내비게이션 | 68px 플로팅 필, 뒤로가기 없는 동일 폭 4열 고정 |
| 전역 헤더 | 64px, 제목·실제 시장지수·3개 동작 |
| 모바일 좌우 여백 | 18–20px |
| 섹션 사이 구분 | 10px 어두운 밴드 |
| 섹션 내부 여백 | 모바일 26px, 넓은 화면 32px |
| 빠른 기능 버튼 | 가로 스크롤 카드, 모바일 높이 약 92px |
| 주요 검색창 | 52px |
| 상위 화면 탭 | 텍스트 밑줄 또는 작은 선택 필 |
| 종목상세 탭 | 50px, 밑줄, 가로 스크롤 허용 |
| 페이지 제목 | 전역 헤더 20–21px |
| 섹션 제목 | 23px |
| 분석 본문 | 13–14px, 줄높이 1.55–1.65 |

카드는 독립된 선택 단위, AI 설명, 핵심 요약에만 사용한다. 긴 데이터 화면은 카드 중첩 대신 섹션 밴드, 여백, 행 구분선을 사용한다.

## 5. 상태와 접근성

- 상승·하락은 색상과 함께 부호와 문구를 표시한다.
- 로딩은 예상 화면 위치를 유지하는 오버레이 또는 스켈레톤을 사용한다.
- 신호 없음과 데이터 지연은 오류처럼 숨기지 않고 정상 상태로 설명한다.
- 필터와 탭은 키보드 포커스를 명확히 표시한다.
- 전체 메뉴는 열기 버튼으로 포커스를 돌려주고, `Escape`와 내부 포커스 순환을 지원한다.
- 모바일 하단 내비게이션과 팝업이 본문 마지막 내용을 가리지 않도록 안전영역 여백을 둔다.
- 360px, 390px, 1200px와 좁은 재배치 압력에서 가로 페이지 스크롤이 생기지 않아야 한다.

## 6. 구현 위치

- `app/staging_app.py` — 스테이징 전용 스타일과 IA 스크립트 주입
- `app/static/staging/toss-ia.js` — 내비게이션, 페이지 프레이밍, 종목상세 재배치
- `app/static/staging/toss-fidelity.css` — 목적 중심 레이아웃, 간격, 터치 크기, 상태별 대비
- `tests/test_staging_dark_theme.py` — 스테이징 격리, 자산 제공, 구조·크기 계약 검증

프로덕션으로 승격할 때는 스테이징 DOM 변환을 그대로 복사하지 않고, 검증된 구조를 프로덕션 HTML과 컴포넌트에 직접 반영한다.
