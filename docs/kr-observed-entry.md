# 국내 예비 포착 이후 장중 매수 확정

2026-10-23부터 `same-session-observed-entry-v2`를 적용한다. 2026-10-21의 `same-session-observed-entry-v1`, 기존 v8.1 종가 승인 주문, 과거 공개 이력은 그대로 읽고 재생한다. 새 경로는 실제로 관측·저장한 후보에만 적용하며 과거 분봉으로 후보를 소급 생성하지 않는다.

1. 현재 대상군 자격과 기존 H1 예비/매수 조건을 통과한 종목의 최초 관측 시각·고정 진입 확인선을 저장한다. 장중 누적 거래량은 최근 20개 봉인 분봉 경로의 같은 시각 누적 거래량과 비교한다. 유효 경로가 3개 미만이면 20일 평균 일거래량을 정규장 경과 시간만큼만 배분한다. 기존 보유, 대기 주문, 당일 거래가 있으면 새 후보를 만들지 않는다.
2. 예비 포착 거래량 기준은 0.75배, 실제 매수 확정 H1 기준은 1.0배로 분리한다. 예비 후보가 정규 대상군 스냅샷에 실제 게시된 뒤에만 확정을 허용한다. 최초 관측 또는 게시 시각을 포함한 분봉은 제외한다. 이후 가장 최근 완료 분봉의 종가가 확인선 이상이고 기존 매수·추격 방지·재진입·안전장치와 독립 근거를 통과해야 확정한다. 누락된 중간 돌파를 뒤늦게 체결로 만들지 않는다.
3. 독립 근거는 최신 완료 거래일 가격·수급 기준으로 다시 평가하고, 중대 공시는 실제 관측 시각까지 포함한다. 입력과 판단을 후보 원장에 고정한다. 미래·180초 초과 평가, 다른 종목/기준일, 불완전 데이터는 확정할 수 없다.
4. 전략 진입 관측가는 해당 완료 분봉 종가다. 실제 계좌 주문·체결을 의미하지 않는다. 진입 분봉 이후의 분봉부터 기존 손절·수익확정 규칙을 적용한다.
5. 후보는 하루 한 번만 만들고 보유 충돌·대상군 제외·추격·재진입·위험 공시처럼 구조적인 위험 조건 위반 시 해제한다. 분봉·현재가·독립 근거의 일시적인 누락이나 지연은 `watching` 상태에서 중지 사유를 기록하고, 같은 날 새 완료 분봉과 정상 근거가 들어오면 관측을 재개한다. 끊긴 구간의 가격을 소급 체결하지 않는다. 미확정 후보는 15:30에 만료한다.
6. 예비 포착과 확정은 서로 다른 알림 키를 사용한다. 관심종목과 시장 알림은 같은 전이 키를 공유한다. 새 확정은 180초 안에서만 전송하며 전송 직전에도 만료를 확인한다. 구독 기준선과 기존 알림 설정을 유지한다.

관측은 기존 정규 대상군 갱신 주기(통상 5분)를 따른다. 틱 단위 즉시 주문 기능은 아니다. 데이터 재검증 대상 종목은 기존과 같이 새 확정·알림에서 제외한다.

실계좌 어댑터는 `kr-live-order-regular-session-v1` 가드를 반드시 호출한다. 매수·부분매도·전량매도 모두 현재 KRX 거래일의 09:00 이상 15:30 미만에만 허용하며, `intraday_execution_verified=true`, `intraday_order_verified=true`, 완료 분봉 확정 시각 180초 이내, 양수 가격을 동시에 요구한다. 장 마감 신호는 분석 화면에 남을 수 있지만 장 마감 뒤 새 주문으로 바뀌지 않는다. 장중 매도 이벤트는 15:40 일봉 시각 대신 실제 완료 분봉 확정 시각을 기록한다.

원장은 `quant_signal_observed_entry`에 저장한다. 표준 DB 초기화로 테이블을 추가하며 별도 과거 데이터 이관은 없다. 새 진입의 주문 해시와 확인 분봉을 이후 재생 때 검증한다. 누락·불일치 시 해당 종목을 재검증 대기로 분리한다. 후보 원장의 독립 근거·주문 입력은 공개 응답에 포함하지 않는다.

검증 계약: `SIG-KR-OBSERVED-ENTRY-001`. 기존 전략 회귀, 관측/완료 분봉 경계, 공시, 재시작, 재생, API 공개 필드, 알림 중복/만료는 결정적 테스트로 검증한다. 실시간 원천·알림 준비 상태와 UI는 기존 live/e2e 계약과 함께 검사한다.
